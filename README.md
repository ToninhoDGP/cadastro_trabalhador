Sistema web simples para cadastro e recepção de dados de colaboradores desenvolvidos em PHP e HTML no ambiente local XAMPP.

---

## 📌 Sobre o Projeto

Este projeto consiste em um formulário web interativo de cadastro de trabalhadores desenvolvido como atividade prática. O sistema recebe os dados inseridos pelo usuário, realiza o processamento dos campos no servidor local via PHP e apresenta uma tela de confirmação estruturada com formatação de valores e mensagem personalizada.

### 🛠️ Funcionalidades

* **Formulário de Cadastro (`ficha_trabalhador.html`)**: Captura de Nome Completo, Idade, Profissão, Salário Pretendido e Experiência Anterior com validação dos campos obrigatórios.
* **Painel de Processamento (`painel_trabalhador.php`)**: Recebimento dinâmico das variáveis, formatação monetária em Reais (R$) e exibição de mensagem personalizada.

---

## 📂 Estrutura de Arquivos

* `ficha_trabalhador.html`: Interface do formulário de entrada
* `painel_trabalhador.php`: Script PHP de recepção e exibição de dados

---

## 🚀 Como Executar o Projeto

1. **Pré-requisitos**: Ter o XAMPP instalado com o módulo Apache iniciado.
2. **Instalação**: Mova/copie a pasta do projeto para o diretório htdocs do XAMPP (`C:\xampp\htdocs\cadastro_trabalhador`).
3. **Acesso no Navegador**: Abra o seu navegador e acesse `http://localhost/cadastro_trabalhador/ficha_trabalhador.html`.
